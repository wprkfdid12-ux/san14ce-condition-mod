# 삼국지14 CE 기색(장수 컨디션) 모드

장수마다 달마다 기색(절정·호조·보통·부진·최악)이 정해져 통솔·무력·지력·정치·매력이 +4/+2/0/−2/−4 오르내리고,
나이에 따라 능력치가 자라고 늙는 모드입니다. 통합패치와 따로 설치·제거되며 다른 모드 파일은 건드리지 않습니다.

> **필수: 통합패치 17번 「능력치 상한 200 해금」** — 이게 없으면 기색 모드가 게임 안에서 꺼집니다.
> 통합패치 설치기에서 17번을 켜고 설치한 뒤 이 모드를 설치하세요.

게임 2026-11-05 업데이트판 + 통합패치 R43 이상에서 동작합니다.

## 처음 받는 분 (한 번만)
1. 아래 링크를 눌러 설치기를 받습니다.
   **[기색 모드 설치기 v1.2.5 받기](https://github.com/wprkfdid12-ux/san14ce-condition-mod/raw/main/updates/v1.2.5/KisaekSetup_v1.2.5.exe)**
2. 받은 `KisaekSetup_v1.2.5.exe` 를 바탕화면 같은 아무 폴더에 두고 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
3. 설치기에서 **[설치]** 를 누르면 끝입니다.

## 그다음부터
설치기를 켜면 깃허브에 새 판이 있는지 알려 줍니다. **[업데이트]** 만 누르면 새 판을 받아 바로 적용합니다(설치기도 새 판으로 바뀝니다).
예전 판으로 돌아가고 싶으면 **[버전 되돌리기]** 에서 판을 고르세요. 어느 쪽이든 설정(Condition.ini)은 그대로입니다.

## 설치되는 파일
게임 폴더의 `SAN14_Condition.dll`, `SAN14Mods\modules\Condition.ini` 두 개뿐입니다. [제거]를 누르면 이 두 파일만 지웁니다.
세이브에는 항상 원래 능력치·개성이 저장되므로, 나중에 모드를 지워도 세이브는 안전합니다.
